# Crowdfunding Web Application (PHP + MySQL)

A web-based crowdfunding platform built as a **Web Technologies course project**. The system allows users to register/login, create fundraising campaigns, browse campaigns, and track donations with a structured database-backed workflow.

---

## ✨ Features

### ✅ Authentication & Users
- Email/password registration and login
- Basic session-based authentication
- User roles supported (if applicable): Admin / User (Creator/Donor)

### ✅ Campaign Management
- Create a new campaign with title, description, goal amount, and category
- View all campaigns and campaign details
- Update / manage campaigns (if implemented)
- Campaign progress tracking (goal vs raised)

### ✅ Donations & Tracking
- Donate to campaigns (with validation)
- Donation history tracking
- Aggregate totals per campaign (raised amount)

### ✅ Additional Modules (if implemented)
- Categories for campaigns
- Comments on campaigns
- Notifications / basic updates
- Admin management panels
- Analytics / dashboard summary

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript  
- **Backend:** PHP  
- **Database:** MySQL  
- **Tools:** XAMPP / WAMP / Laragon, phpMyAdmin
